# 支撐壓力選線邏輯規格

**版本：** v5  
**日期：** 2026-05-12  
**資料來源：** `OUTPUT/csv/sr_zone_rank_full.csv`（34 產業 × 3 趨勢 × 3 期別回測結果）

---

## 一、趨勢判斷

每次選線前先判斷當日趨勢，所有期別共用同一判斷。

```
bull:     close > MA20  且  MA20 > MA60
bear:     close < MA20  且  MA20 < MA60
sideways: 其餘（不滿足 bull 也不滿足 bear）
```

**MA 保證性質：**
- `bull` 趨勢下，MA20 < close 和 MA60 < close 為數學確定，以 MA20/MA60 作為支撐時驗證必過。
- `bear` 趨勢下，MA20 > close 和 MA60 > close 為數學確定，以 MA20/MA60 作為壓力時驗證必過。
- 其餘指標（CDP 系列、VP 系列、回溯高低）均為統計性質，須執行時驗證。

## 二、核心演算法

### 常數定義

```python
# 各期別最小區間寬度（相對於 close 的百分比）
MIN_WIDTH = {
    'short': 0.01,   # 1.0%
    'mid':   0.02,   # 2.0%
    'long':  0.05,   # 5.0%
}

# 保底：各期別固定錨定對（N 日最低 ＋ N 日最高）
# 選用原則：僅需 OHLCV，R > S 由定義保證，無條件輸出
LAST_RESORT = {
    ('short', 'bull'):     ('low_10d',  'high_10d'),
    ('short', 'bear'):     ('low_10d',  'high_10d'),
    ('short', 'sideways'): ('low_10d',  'high_10d'),
    ('mid',   'bull'):     ('low_20d',  'high_20d'),   # N 日高低，R > S 由定義保證
    ('mid',   'bear'):     ('low_20d',  'high_20d'),
    ('mid',   'sideways'): ('low_20d',  'high_20d'),
    ('long',  'bull'):     ('low_240d', 'high_240d'),  # N 日高低，R > S 由定義保證
    ('long',  'bear'):     ('low_240d', 'high_240d'),
    ('long',  'sideways'): ('low_240d', 'high_240d'),
}
```

### 兩層選線策略

目標：**盡可能畫出線**，只在真正無法產生有效值時才放棄。

```
主要邏輯
  含括率 > 70% + R > S + min_width
      ↓ 全部候選失效
保底（N 日最低 ＋ N 日最高）
  無條件輸出，R > S 由定義保證
      ↓ 掛牌不足，N 日資料無法計算
  不畫線
```

### 選線函式

```python
def select_sr(candidates, close, vp_available, period, trend):
    """
    Parameters
    ----------
    candidates   : list of (support_ind, resistance_ind, needs_vp, containment)
                   依優先順序排列
    close        : float，當日收盤價
    vp_available : bool，該股 Volume Profile 資料是否可用
    period       : 'short' | 'mid' | 'long'
    trend        : 'bull' | 'bear' | 'sideways'

    Returns
    -------
    (S_value, R_value) 或 None（僅掛牌不足無法計算時發生）

    Notes
    -----
    - close 可在 [S, R] 之間、S 之下、或 R 之上，皆為有效輸出。
    - 圖上不標示突破或跌破方向，只畫 S、R 兩條水平線。
    """

    for (sind, rind, needs_vp, cont) in candidates:
        if cont <= 0.70:
            continue                                  # 含括率不足
        if needs_vp and not vp_available:
            continue                                  # VP 資料不可用

        S = calc(sind)
        R = calc(rind)

        if R <= S:
            continue                                  # 無效區間
        if (R - S) / close < MIN_WIDTH[period]:
            continue                                  # 區間過窄

        return (S, R)

    # 保底：N 日最低 ＋ N 日最高，無條件輸出
    sind, rind = LAST_RESORT[(period, trend)]
    return (calc(sind), calc(rind))   # None 僅在掛牌不足無法計算時發生
```

### 驗證規則摘要

| 層級 | 含括率門檻 | R > S | min_width | 觸發條件 |
|------|----------|-------|-----------|---------|
| 主要邏輯 | > 70% | ✅ | ✅ | 正常情況 |
| 保底 | — | — | — | 主要邏輯全部失效 |
| 不畫線 | — | — | — | 掛牌不足，N 日資料無法計算 |

> close 可在區間外：允許 `close > R` 或 `close < S`，各層均不將此列為失效條件。

## 三、短期候選清單（三種趨勢通用）

短期以**成交量集中區**與**近期實際測試過的價格邊界**為主。

**排序依據：VP5 可用時優先（較緊且有量的意義），其次近 5 日實際高低邊界。**

| 優先 | 支撐指標 | 壓力指標 | 需VP | 含括率 | 平均寬度 | 技術意義 |
|-----|---------|---------|-----|------|---------|---------|
| 1 | `vp5_val` | `high_5d` | ✅ | 77–84% | ~5–6% | 量區支撐 + 近 5 日高點壓力 |
| 2 | `low_5d` | `vp5_vah` | ✅ | 73–79% | ~4–5% | 近 5 日低點支撐 + 量區壓力 |
| 3 | `low_5d` | `high_5d` | — | ~90% | ~7.5% | 近 5 日實際測試過的邊界 |

> VP5 資料可用時：優先 1 → 2 → 3  
> VP5 資料不可用時：跳過 1、2，直接從 3 開始  
> 全部失效後，Tier 2 以不設含括率門檻再跑一次；Tier 3 錨定對（`low_10d + high_10d`）最終保底。

**剔除說明：** 原候選 #3（`ma5+high_5d`）、#4（`low_5d+ma10`）、#5（`ma5+ma10`）回測含括率均未達 70%（多頭/盤整趨勢下僅 20–60%），不符合 Tier 1 門檻且對選線結果影響極小，於 v5.1 移除。

## 六、不顯示線的情境

兩層機制執行後，幾乎所有情況都能畫出線。唯一合理放棄的情境：

| 情境 | 說明 |
|------|------|
| 股票掛牌不足資料期間 | N 日高低尚無足夠歷史資料，保底錨定對無法計算 |

上述情境發生時，該期別靜默略過，不畫線，不顯示任何替代內容。

---

## 七、圖形呈現規則

- 每個期別各輸出 **一條支撐線（S）** 和 **一條壓力線（R）**，兩條水平線。
- close 可在 S 之下、S/R 之間、或 R 之上，圖上不另外標示方向。
- 若某期別使用保底輸出，線的視覺樣式維持不變，不另外標示。
- 若某期別真正找不到有效組合，靜默略過，不以任何替代內容填補。
